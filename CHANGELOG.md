# Changelog

## v1.0.0 - 2026-11-23

- First release: Tabler Icons for every Filament 4 and 5 UI icon alias (222 in Filament 5.12), registered with `TablerIcons::make()`.
- Outline (default) and filled styles: `->filled()`, plus per-alias and per-icon style overrides.
- `Tabler` enum with all 6,275 icons from secondnetwork/blade-tabler-icons 3.x.
