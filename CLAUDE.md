# CLAUDE.md

Tabler Icons pack for Filament 4 and 5, built on the filafly/filament-icons core.

- `src/TablerIcons.php`: the plugin. `$iconMap` maps every Filament icon alias to a `Tabler` case, using the outline case. Keys are alias strings, not `*IconAlias` constants, because some constants only exist in later 4.x releases. `$currentStyle` defaults to Outline so style overrides work without a global style.
- `src/Enums/Tabler.php`: generated by `php bin/generate-icon-cases.php` from secondnetwork/blade-tabler-icons (Blade prefix `tabler`). Older `-f` duplicates of `-filled` icons are skipped. Don't edit by hand.
- `src/Enums/TablerStyle.php`: Outline (no suffix) and Filled (`-filled`).

Commands: `composer test` (PHPUnit + Testbench), `vendor/bin/pint`. The ship gate runs `npm test`, which runs composer update then PHPUnit.

`TablerIconsTest::test_every_filament_alias_is_mapped` fails when a new Filament release adds an alias: map it in `$iconMap`.
